# GLYMIZE local rebrand preview

This local-only overlay introduces the permanent GLYMIZE product identity and a redesigned bilingual welcome screen.

## Included

- Permanent product name: **GLYMIZE**
- English UI font: **Manrope** (modern geometric sans-serif)
- Persian UI font: **Vazirmatn**
- New English and Persian welcome screen
- RTL/LTR-aware language switching
- Updated logo and application icons
- New light medical-technology theme
- Legacy browser-storage migration from previous product names
- Responsive and keyboard-focus states

## Important

The current preview loads fonts from Google Fonts. Before a production/offline clinical release, the selected fonts should be self-hosted through the application build and reviewed for licensing, privacy, and offline behavior.

The installer does not run `git commit`, `git push`, change a remote, create a pull request, or write to GitHub.
