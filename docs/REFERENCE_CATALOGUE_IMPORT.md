## قاعدهٔ حیاتی برای ایران

این snapshot **فهرست بازار ایران نیست**. هیچ برند، قدرت، قلم، ویال یا ترکیب
ثابت از آن نباید به عنوان موجود/ثبت‌شده در ایران نمایش داده شود. برای هر
فرآوردهٔ ایران باید Admin، منبع مجاز (رجیستری رسمی، export تأییدشده یا ورود
دستی با سند) را ثبت و بعد یک `brand_market_entry` مستقل بسازد. اولویت برند نیز
فقط در سطح سازمان و پس از این تأیید قابل تنظیم است.

## اثر بر منطق بالینی

کاتالوگ مرجع، دادهٔ ارائه و منبع است؛ قاعدهٔ درمانی یا دوز نیست. افزودن یا
تغییر آن هیچ پروتکل Type 2 را فعال نمی‌کند. هر تغییر پروتکل باید بازبینی
بالینی، تست، تأیید و امکان rollback داشته باشد.
