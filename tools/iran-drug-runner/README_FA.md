# استخراج‌گر محلی اطلاعات دارویی GLYMIZE

این برنامه فقط روی کامپیوتر ادمین و آدرس `127.0.0.1:8765` اجرا می‌شود. هیچ
پورت عمومی باز نمی‌کند و دریافت منابع رسمی از اینترنت ایران انجام می‌شود.

## محدودیت فعلی NFI

تا زمانی که ساختار واقعی خروجی NFI و روش مجاز دانلود آن تأیید نشده، فایل
`nfi-latest.xlsx` باید در پوشه `input` قرار گیرد یا مسیر آن در متغیر
`GLYMIZE_NFI_FILE` ثبت شود. نبود این فایل باعث توقف انتشار می‌شود؛ داده سه
بیمه بدون مرجع NFI منتشر نخواهد شد.

## اجرای ویندوز

```powershell
cd C:\Users\abbas\GLYMIZE\tools\iran-drug-runner
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
playwright install chromium
$env:GLYMIZE_NFI_FILE="C:\مسیر\nfi-latest.xlsx"
python runner_server.py
```

سپس در `/admin/data-updates` روی «بررسی اتصال» و بعد «استخراج از چهار منبع»
بزنید. اگر مرورگر دسترسی localhost را مسدود کرد، فایل
`runs/<job-id>/output/glymize-drug-bundle.json` را از همان صفحه به‌صورت دستی
انتخاب کنید.

## قواعد ایمنی

- خطای هر منبع، انتشار را متوقف می‌کند.
- واحد نامشخص قیمت، نیازمند بازبینی است.
- ریال با تقسیم بر ۱۰ به تومان تبدیل می‌شود.
- کد هر بیمه در namespace همان بیمه نگه‌داری می‌شود.
- تطبیق با اطمینان کمتر از ۹۰٪ منتشر نمی‌شود.
- فایل خام و checksum هر اجرا برای ممیزی نگه‌داری می‌شود.
- فقط ردیف‌های مطابق `scope_allowlist.json` وارد بسته می‌شوند. فهرست فعلی
  کاتالوگ بازبینی‌شدهٔ دیابت است؛ حوزه‌های همراه پس از تأیید علمی به همین فایل
  اضافه می‌شوند.
