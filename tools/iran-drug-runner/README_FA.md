# استخراج‌گر محلی اطلاعات دارویی GLYMIZE

این برنامه فقط روی کامپیوتر ادمین و آدرس `127.0.0.1:8765` اجرا می‌شود. هیچ
پورت عمومی باز نمی‌کند و دریافت منابع رسمی از اینترنت ایران انجام می‌شود.

## فایل NFI

فایل `nfi-latest.xlsx` باید در پوشه `input` قرار گیرد یا مسیر آن در متغیر
`GLYMIZE_NFI_FILE` ثبت شود. واردکننده شیت‌های `NFI_Products*` را به‌صورت
خودکار پیدا و ترکیب می‌کند و همچنان قالب ساده قدیمی را نیز می‌پذیرد. نبود
این فایل باعث توقف انتشار می‌شود؛ داده سه بیمه بدون مرجع NFI منتشر نخواهد شد.

در قالب غنی NFI، ستون `Generic_INN` مبنای تطبیق ژنریک است. نام فرآورده از
فیلد `نام` داخل `All_Label_Value_JSON` و در نبود آن از `NFI_Title_FA` خوانده
می‌شود. IRC و GTIN از ستون اختصاصی یا متن خام بازیابی می‌شوند؛ هیچ کد ساختگی
تولید نمی‌شود. امتیاز `Match_Confidence_0_100` نیز حفظ می‌شود و رکورد زیر
۹۰٪ برای بازبینی ادمین باقی می‌ماند.

## اجرای ویندوز

```powershell
cd C:\Users\abbas\GLYMIZE\tools\iran-drug-runner
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
playwright install chromium
$env:GLYMIZE_NFI_FILE="C:\مسیر\nfi-latest.xlsx"
python runner_server.py
```

پس از هر به‌روزرسانی کد Runner، حتی اگر محیط مجازی از قبل ساخته شده است، این
دستور را دوباره اجرا کنید تا وابستگی‌های جدید مانند دیتابیس منطقه زمانی
ویندوز نصب شوند:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

سپس در `/admin/data-updates` روی «بررسی اتصال» و بعد «استخراج از چهار منبع»
بزنید. اگر مرورگر دسترسی localhost را مسدود کرد، فایل
`runs/<job-id>/output/glymize-drug-bundle.json` را از همان صفحه به‌صورت دستی
انتخاب کنید.

## قواعد ایمنی

- خطای هر منبع، انتشار را متوقف می‌کند.
- واحد نامشخص قیمت، نیازمند بازبینی است.
- ریال با تقسیم بر ۱۰ به تومان تبدیل می‌شود.
- کد هر بیمه در namespace همان بیمه نگه‌داری می‌شود.
- تطبیق با اطمینان کمتر از ۹۰٪ منتشر نمی‌شود.
- فایل خام و checksum هر اجرا برای ممیزی نگه‌داری می‌شود.
- فقط ردیف‌های مطابق `scope_allowlist.json` وارد بسته می‌شوند. فهرست فعلی
  کاتالوگ بازبینی‌شدهٔ دیابت است؛ حوزه‌های همراه پس از تأیید علمی به همین فایل
  اضافه می‌شوند.
